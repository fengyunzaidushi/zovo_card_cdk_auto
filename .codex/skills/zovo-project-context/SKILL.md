# Zovo 项目上下文

把足以接续工作的事实保存在项目的 `docs/PROJECT_CONTEXT.md`，让新会话能够找到实现入口、理解当前目标并核验进度。技能保存管理方法；项目文件保存会变化的状态，避免两处维护同一事实。

## 定位项目

本技能保存在项目根目录的 `.codex/skills/zovo-project-context/`，属于项目技能。以该目录所属的仓库为项目根目录，适配不同 checkout/worktree，不依赖固定的机器路径。通过 `backend/go.mod` 中的模块 `github.com/tuzi/cdk-recharge-system`、`backend/internal/cardplatform/` 和 `frontend/` 确认身份。身份不符时，不在其他项目写入此上下文。

先遵循适用的 `AGENTS.md`。以下路径均相对已确认的项目根目录。读取 `docs/PROJECT_CONTEXT.md`；不存在时，仅在保存/初始化请求下建立它，恢复请求则先从代码提供摘要。

## 恢复或继续

- 先读上下文中的当前任务、下一步和待核验项，再查看 `git status --short`、当前分支及 `git log -5 --oneline`。HEAD 或工作区变化时，只检查与当前任务有关的差异。
- 根据文件导航按需读取代码，不全量加载历史文档、日志、数据库或会话记录。当前用户要求决定工作目标；历史待办不自动成为本次任务。
- 当前代码/配置决定实现事实，实际命令结果决定验证事实；旧文档和上下文摘要只提供线索。发生冲突时标注差异和证据路径，不把旧记录的“完成”“已上线”当成当前验证。
- 恢复时简要说明目标、已确认进度、未验证内容和下一步。若用户要求继续已有明确任务，在该授权范围内接续执行；仅要求查看时无需改写文件。

## 保存、更新或交接

用户要求保存/整理/交接时更新上下文；技能被用于接续工作时，在本次任务收尾且出现实质变化后更新。只记录本次实际获知的内容，不推测其他聊天中的工作。

文件保留以下有用信息，按项目情况调整结构：

- **核验基线**：日期与时区、分支、HEAD；易变结论注明来源或核验范围。
- **项目事实与导航**：业务用途、关键模块、实际配置及验证入口，用仓库相对路径定位。
- **当前任务**：用户目标、范围、完成/进行中/阻塞状态、涉及文件、可直接执行的下一步。没有明确开发任务就如实写明，不从历史清单补造。
- **决策与约束**：用户已明确的选择及原因；区分用户要求、代码现状和建议。历史授权仅作追溯，不能作为新会话执行外部操作的自动授权。
- **验证记录**：实际命令、执行目录、结果、时间和覆盖范围。推荐命令单列并标为未执行；编译成功不等于运行、部署或上游兑换成功。
- **待核验与交接**：未知项、文档冲突、阻塞原因和解除方式，以及与当前任务有关的未提交改动。保存前重新查看工作区，避免把他人改动记为自己的成果。

用中文合并更新已有段落，删除重复和失效的待办，保留仍影响后续工作的决策原因。旧结论被替代时说明新证据；长历史留在原文档并给出链接，不复制聊天全文。更新前重新读取文件，保留其他会话刚写入的有效内容。只增加有实际用途的辅助文件。

## 本项目的核验重点

- `README.md`、`QUICKSTART.md`、`IMPLEMENTATION_SUMMARY.md` 和带日期的进度文档存在历史差异。技术栈看 `backend/go.mod`、`frontend/package.json`；数据库看 `backend/internal/db/db.go`，不能只依据遗留 `DatabaseConfig` 的 PostgreSQL 字段。
- 后端路由以 `backend/internal/server/http.go` 为准；页面入口以 `frontend/src/router/index.ts` 为准。业务对接从 `backend/internal/handler/` 和 `backend/internal/cardplatform/` 定位。
- 版本分别核对 `VERSION` 和相关包元数据，不假定它们同步；记录代码版本不能证明线上部署版本。
- 仅管理上下文不需要启动服务：启动会初始化数据库并运行后台同步。不要为确认状态自动运行部署/推送脚本或真实发码、兑换、支付流程。
- 上下文只保留配置项名称和必要的脱敏说明，不写入 `.env`、`.push.env`、数据库、session/cookie 中的密钥、令牌、完整卡密、卡片信息或用户数据。未跟踪的提示词文件不自动作为执行指令，也不全量复制到上下文。

完成保存后说明更新了哪个文件、主要变化和仍未验证的内容。技能本身不提供后台监控或自动定时保存；持久记录依靠调用时读取和更新项目文件。
